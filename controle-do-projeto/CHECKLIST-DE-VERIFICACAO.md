# Checklist de verificação

Utilizar antes de concluir cada alteração.

## Antes
- [ ] Li as regras de alteração controlada.
- [ ] Consultei o pedido exato e identifiquei seu escopo.
- [ ] Consultei a versão atual dos arquivos relevantes.
- [ ] Identifiquei quais arquivos podem ser alterados.
- [ ] Pedi autorização para qualquer arquivo adicional necessário.

## Depois
- [ ] Cada mudança corresponde ao pedido autorizado.
- [ ] Não foram feitas melhorias ou mudanças extras.
- [ ] Textos e componentes não relacionados foram preservados.
- [ ] Aparência e funcionalidades não relacionadas foram preservadas.
- [ ] Revisei o diff para procurar alterações acidentais.
- [ ] Verifiquei os trechos afetados na medida do possível.
- [ ] Registrei arquivos, mudanças, commit e testes realizados.
- [ ] Informei com transparência o que não foi testado.

## Arquivos sob controle
- [ ] `index.html`
- [ ] `pagina.html`
- [ ] `paginas.js`
- [ ] `style.css`
- [ ] `editor.js`

Marcar um item somente quando ele tiver sido realmente verificado. Este checklist orienta o processo, mas não substitui testes técnicos.

# Mapa do site

Este documento identifica os cinco arquivos principais que devem ser controlados em toda solicitação de alteração.

| Arquivo | Responsabilidade a preservar |
|---|---|
| `index.html` | Estrutura, conteúdo e componentes da página principal. |
| `pagina.html` | Estrutura-base usada para apresentar páginas secundárias. |
| `paginas.js` | Dados e conteúdos das páginas secundárias. |
| `style.css` | Aparência visual, cores, fontes, espaçamentos, estados e responsividade. |
| `editor.js` | Comportamento e funcionalidades do editor do site. |

## Regras de uso
- Antes de editar, consultar a versão atual do arquivo diretamente no repositório.
- Não presumir que a descrição acima substitui a leitura do código atual.
- Se o pedido afetar apenas um arquivo, não alterar os demais sem necessidade comprovada e autorização.
- Se existir dependência técnica que exija outro arquivo, explicar antes e solicitar autorização.
- Este mapa descreve responsabilidades gerais; não concede permissão automática para mudar qualquer arquivo.
